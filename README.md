# StatArb-Quant-Platform-Arbitrage-Statistique-par-Coint-gration-et-Filtre-de-Kalman-
Plateforme quantitative de Pairs Trading (Arbitrage Statistique). Modélisation par cointégration (Engle-Granger), estimation dynamique du ratio de couverture par Filtre de Kalman, test d'Ornstein-Uhlenbeck et backtester institutionnel avec gestion des frictions de marché.
